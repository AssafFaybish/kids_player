# native-reference — canonical copies of every hand-maintained native file

`android/` is committed to git, so these copies are DISASTER RECOVERY (a fresh
`npx cap add android`), not a routine copy step. Keep them in sync with `android/`.

## The manual touch points inside `android/`

| # | File | What's custom |
|---|------|---------------|
| 1 | `app/src/main/java/com/assaf/kidsplayer/MainActivity.java` | YouTube-navigation blocking, real fullscreen, popup blocking, all three `registerPlugin(...)` calls **before** `super.onCreate()`, `onNewIntent` share handling, and the site-viewer hooks (`onBackPressed` / `onPause` / `onResume`) |
| 2 | `app/src/main/java/com/assaf/kidsplayer/KidsNativePlugin.java` | keep-awake (F7), share inbox (F12b), APK installer (F14), kiosk lock-task, device auth |
| 3 | `app/src/main/java/com/assaf/kidsplayer/GoogleAuthPlugin.java` | Play-Services authorization, `drive.file` scope ONLY |
| 4 | `app/src/main/java/com/assaf/kidsplayer/KidsWebPlugin.java` | v1.0.45 — the restricted site viewer (the only place a child's web navigation is enforced) |
| 5 | `app/src/main/AndroidManifest.xml` | `allowBackup=false`, free rotation (no `screenOrientation`), Android-TV bits (`leanback`/`touchscreen` optional, `android:banner`, `LEANBACK_LAUNCHER`), SEND intent-filter, `REQUEST_INSTALL_PACKAGES`, FileProvider |
| 6 | `app/src/main/res/values/strings.xml` | `share_target_label` |
| 7 | `app/src/main/res/xml/file_paths.xml` | `app_updates` + `app_exports` paths |
| 8 | `app/build.gradle` | ONE appended line: `apply from: rootProject.file("../release/android-release.gradle")`, plus `androidx.biometric` |
| 9 | `app/src/main/res/mipmap-anydpi-v26/ic_launcher*.xml` | `<inset>` removed from `<background>` after icon regeneration (see DEVELOPMENT.md §10) |
| 10 | *(nothing else)* | everything remaining is generated by Capacitor |

After a regeneration: copy files 1-7 from here, re-append line 8, redo 9 if icons were
regenerated, then `npx cap sync android` and rebuild.

⚠️ **Keep every pair byte-identical.** Only some pairs have an invariants guard (the
kiosk halves, `shareFile`, the site viewer); the manifest had none and drifted for three
releases — a rebuild from here would have shipped an APK with no Android-TV support at
all. Until a general pair-diff test exists, `diff` them by hand when you touch one.
