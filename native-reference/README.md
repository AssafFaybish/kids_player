# native-reference — canonical copies of every hand-maintained native file

`android/` is committed to git, so these copies are DISASTER RECOVERY (a fresh
`npx cap add android`), not a routine copy step. Keep them in sync with `android/`.

## The manual touch points inside `android/`

| # | File | What's custom |
|---|------|---------------|
| 1 | `app/src/main/java/com/assaf/kidsplayer/MainActivity.java` | YouTube-navigation blocking, real fullscreen, popup blocking, `registerPlugin(KidsNativePlugin.class)` **before** `super.onCreate()`, `onNewIntent` share handling |
| 2 | `app/src/main/java/com/assaf/kidsplayer/KidsNativePlugin.java` | keep-awake (F7), share inbox (F12b), APK installer (F14) |
| 3 | `app/src/main/AndroidManifest.xml` | `allowBackup=false`, `sensorLandscape`, SEND intent-filter, `REQUEST_INSTALL_PACKAGES` |
| 4 | `app/src/main/res/values/strings.xml` | `share_target_label` |
| 5 | `app/src/main/res/xml/file_paths.xml` | `<external-files-path name="app_updates" path="updates/"/>` |
| 6 | `app/build.gradle` | ONE appended line: `apply from: rootProject.file("../release/android-release.gradle")` |
| 7 | `app/src/main/res/mipmap-anydpi-v26/ic_launcher*.xml` | `<inset>` removed from `<background>` after icon regeneration (see DEVELOPMENT.md §10) |
| 8 | *(nothing else)* | everything remaining is generated by Capacitor |

After a regeneration: copy files 1-5 from here, re-append line 6, redo 7 if icons were
regenerated, then `npx cap sync android` and rebuild.
